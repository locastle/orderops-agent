## 已确定的设计决策

1. **Agent 编排**：显式状态机，8 个只读工具，调用预算与降级策略。
2. **知识库**：应用层 BM25 + pgvector 向量检索，RRF 融合，角色权限过滤，强制引用与拒答。
3. **数据**：全部原创合成，180 条故障集分 dev/test/holdout 三段。
4. **评测**：Week 1 建立基线 A/B/C 三套对比，失败模式分类驱动迭代。
5. **模型**：DeepSeek 与 MiniMax 同集对比，用数据决定主力模型，必要时级联。
6. **部署**：本地 Docker Compose；公网 Vercel Hobby + Neon Free，匿名访问受限流与每日预算约束。

## 当前可运行的东西

- `packages/shared`：共享领域模型（枚举 + Pydantic 模型），含根因码枚举与诊断输出契约。

- `docker-compose.yml`：PostgreSQL 16 + pgvector 0.8.7、ai-api、enterprise-sim，一键启动。
